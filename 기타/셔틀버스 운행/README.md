# 셔틀버스 운행

출처: 코딩테스트 기출 (원형: Google Code Jam 2010 Qualification C "Theme Park")

### 채점 결과

예제 3개, 랜덤 테스트 600개, 최대 입력(R=1,000,000, K=10,000, N=100) 5개 모두 통과 — 최대 입력 약 0.25초

### 분류

구현, 시뮬레이션, 큐

### 문제 설명

놀이공원 셔틀버스 앞에 N개의 일행이 줄을 서 있다. 버스는 한 번에 최대 K명을 태우고, 하루에 R번 운행한다.

버스가 오면 줄 앞에서부터 일행 단위로 확인해서, 일행 전체가 탈 수 있으면 태우고 못 타면 그 자리에서 출발한다. 같은 일행은 나눠 탈 수 없다. 운행이 끝나면 탔던 일행들은 순서를 유지한 채 줄 맨 뒤로 간다.

승객 1명당 1유로를 받을 때, 하루 총 수익을 구한다.

### 입력

첫째 줄에 R, K, N이 주어진다. 둘째 줄에 각 일행의 인원 g₀ … gₙ₋₁이 주어진다.

### 출력

하루 총 수익을 출력한다.

### 제한

- 1 ≤ R ≤ 1,000,000
- 1 ≤ K ≤ 10,000
- 1 ≤ N ≤ 100
- 1 ≤ gᵢ ≤ K

### 예제

| 입력 | 출력 |
|---|---|
| `4 6 4` / `1 4 2 1` | 21 |
| `3 5 4` / `2 3 1 2` | 14 |
| `5 10 3` / `4 3 2` | 45 |

### 풀이 메모

- 큐로 줄을 그대로 시뮬레이션: 다음 일행을 더해도 K 이하면 태우고 큐 뒤로 보낸다.
- 한 운행에 같은 일행이 두 번 타지 않도록 최대 N개 일행까지만 태운다 (전원이 다 타는 경우 무한루프 방지).
- 총 수익은 최대 10¹⁰이라 `long long` 필요.
